# dsr-test

Minimal Vite app for trying [`@cfpb/design-system-react`](https://github.com/cfpb/design-system-react) locally.

## Setup

```bash
yarn install
```

Link or install the library from the sibling `design-system-react` repo as needed, then:

```bash
yarn dev
```

Styles are loaded in `src/main.tsx` via `import '@cfpb/design-system-react/index.css'`.

Edit `src/App.tsx` to add or exercise components.
